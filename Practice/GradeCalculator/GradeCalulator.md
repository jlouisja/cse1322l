# Grade Calulator

---

_My objective of this project is to caluclate current final grade based on the respective percentages of labs, assignments, quizzes, and exams_

---

## Grading Scale

|     |                      |
| --- | -------------------- |
| A   | Grade >= 89.5        |
| B   | 89.5 > Grade >= 79.5 |
| C   | 79.5 > Grade >= 69.5 |
| D   | 69.5 > Grade >= 59.5 |
| F   | Grade < 59.5         |

| Assignment   | Percentage |
| ------------ | ---------- |
| Labs         | 10%        |
| Assignments  | 35%        |
| Quizzes      | 5%         |
| Midterm Exam | 10%        |
| Final Exam   | 40%        |

## Requirements

the program should have a 7 classes. the first class for lab excercises.
this class takes in the lab number and score. the average score is worth 10% of the final grade. there are 11 labs total.
the second class for homework assignments.
this class takes in the assignment number and score. the average score is worth 35% of the final grade. there are 6 assignments total.
the third class for quizzes.
this class takes in the quiz number and score. the average score is worth 5% of the final grade. there are 3 quizzes total.
the fourth class for exams that takes in the exam type in a string and the score. there are 2 exams total. the midterm exam is worth 10% and the final exam is worth 40%.
the fifth class for grade calulation. this class will prompt the user to enter grades for all graded assignments, labs, exams, and quizzes. After calculating the average for each, the program will calulate the final grade based on the percentages above
and print the average grade for each section as well as the final grade

I would like to add more to program as a 2.0 [^1]

[^1]: I would like to add functionality that allows the user to input completed grades and determine grades needed to gain a perticular final grade.
